# Test plan (manual, devices)

## Сеть
- [ ] Wi-Fi → 4G: соединение восстанавливается, статус узла обновляется.
- [ ] 4G → Wi-Fi: соединение восстанавливается, пиры переподключаются.
- [ ] Потеря связи во время майнинга: сервис не падает, после возврата сети майнинг продолжается.
- [ ] Перезапуск приложения: находятся известные пиры, восстанавливается endpoint.
- [ ] Два устройства в одной Wi-Fi сети видят друг друга.

## Кошелек
- [ ] Перевод на собственный адрес: баланс и история корректны.
- [ ] Перевод на адрес другого устройства: получатель видит поступление.
- [ ] Копирование адреса: в буфере полный корректный адрес.
- [ ] Генерация QR: QR открывается, сканируется и содержит правильный адрес.
- [ ] Pull-to-refresh: баланс и история обновляются без дублей.

## Майнинг
- [ ] Старт майнинга: сервис запущен, уведомление отображается.
- [ ] Стоп майнинга: сервис остановлен, уведомление скрыто, wake-lock освобождён.
- [ ] Начисление 5 TRG за блок: баланс увеличивается ровно на 5 TRG.
- [ ] Запись в историю: появляется транзакция майнинга с корректным временем.
- [ ] Повторный старт/стоп подряд: нет дублей блоков и зависших потоков.

## Чат
- [ ] Отправка текста: сообщение появляется у отправителя и получателя.
- [ ] Приём текста при открытом чате: список обновляется без перезапуска.
- [ ] Уведомление о новом сообщении: приходит при закрытом приложении.
- [ ] Переход по уведомлению: открывается нужный чат с нужным пиром.
- [ ] Перезапуск приложения: история чата сохраняется.
- [ ] Отправка при потере сети: статус «не отправлено», повтор после восстановления.

## Безопасность
- [ ] Восстановление по приватному ключу: адрес и баланс соответствуют ожидаемым.
- [ ] Восстановление по seed-фразе (12/24 слова): аккаунт восстанавливается.
- [ ] Экспорт JSON: файл создаётся и открывается.
- [ ] Импорт JSON полным циклом: экспорт → смена аккаунта → импорт → баланс и история восстановлены.
- [ ] Некорректный JSON/ключ: показывается ошибка, данные не повреждаются.
- [ ] PIN: установка, смена, вход после перезапуска.
- [ ] PIN: неверный ввод, блокировка/задержка, восстановление доступа.
