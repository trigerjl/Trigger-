# Как помочь проекту Trigger

Спасибо за интерес к проекту! Мы приветствуем любые улучшения: код, дизайн, документацию, идеи.

## Как предложить изменения

1. **Форкните репозиторий** (кнопка "Fork" в правом верхнем углу на GitHub).
2. **Создайте ветку** для вашей функции: `git checkout -b feature/my-new-feature`.
3. **Внесите изменения** в код.
4. **Соберите проект** и убедитесь, что он работает (см. ниже).
5. **Сделайте коммит**: `git commit -m "Добавил функцию X"`.
6. **Отправьте изменения** в свой форк: `git push origin feature/my-new-feature`.
7. **Создайте Pull Request** в наш репозиторий (кнопка "New Pull Request").

## Как собрать проект

Требования: Android SDK, Java 8+.
```bash
./gradlew assembleDebug -Pandroid.aapt2FromMavenOverride=/usr/bin/aapt2
```

APK будет находиться в app/build/outputs/apk/debug/app-debug.apk.

Требования к коду

· Язык: Java (Android). Комментарии на русском или английском.
· Стиль: Следуйте существующему стилю кода (отступы 4 пробела, camelCase).
· Сборка: Убедитесь, что проект собирается без ошибок.
· Тесты: Если добавляете новую функцию — добавьте юнит-тест (если возможно).

Что можно улучшить (Ideas)

· UI/UX: Улучшить дизайн экранов, добавить анимации.
· Чат: Добавить реакции на сообщения, стикеры.
· Маркет: Улучшить карточки объявлений, фильтры.
· Безопасность: Найти уязвимости (Bug Bounty — вознаграждение в TRG).
· Документация: Улучшить README, добавить примеры.

Bug Bounty

Если вы нашли уязвимость — не создавайте публичный Issue. Напишите администратору через GitHub (или в Issues с пометкой "security"). Мы вознаградим вас TRG (сумма зависит от критичности).

Спасибо, что помогаете делать Trigger лучше!
